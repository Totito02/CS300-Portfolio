# CS 300 — Data Structures and Algorithms

## SNHU Computer Science Portfolio

This repository contains my work from CS 300: Data Structures and Algorithms at Southern New Hampshire University (SNHU).

The projects demonstrate my understanding of data structures, algorithm efficiency, software design, and C++ programming.

## Project One — Data Structures and Algorithms Analysis

In Project One, I evaluated three data structures: vectors, hash tables, and binary search trees.

I analyzed their runtime complexity using Big O notation and compared their memory requirements to determine which structure would best support the ABCU Advising Assistance Program.

My analysis demonstrated the importance of selecting data structures based on application requirements rather than choosing a solution solely because it is familiar.

## Project Two — ABCU Advising Assistance Program

In Project Two, I developed a C++ application using a binary search tree to organize university course information.

The application allows academic advisors to load course information from a CSV file, display courses in alphanumeric order, search for individual courses, and view their prerequisites.

The program also includes input validation, error handling, and memory management.

# Module Eight Journal Reflection

## 1. What was the problem you were solving in the projects for this course?

The main objective was to develop an efficient program for managing and organizing university course information. The ABCU Advising Assistance Program needed to read course data, organize courses in alphanumeric order, and allow academic advisors to search for individual courses and identify their prerequisites.

In Project One, I analyzed different data structures to determine the most appropriate solution. In Project Two, I implemented the selected solution using C++ and a binary search tree.

## 2. How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by identifying the program requirements and evaluating the advantages and disadvantages of vectors, hash tables, and binary search trees.

I compared these structures based on runtime efficiency, memory usage, and their ability to organize and retrieve information.

Understanding data structures is important because selecting the appropriate structure directly affects program performance and scalability. I selected a binary search tree because it supports searching and allows courses to be displayed in sorted order using inorder traversal.

Throughout the course, I encountered challenges involving C++ syntax, file handling, data structure implementation, and debugging.

One challenge involved loading CSV files into the program. I learned how to identify file path issues, validate input data, and handle errors when a file could not be opened.
